# SurVolté — Concessionnaire Moto 100% en Ligne

SurVolté est la plateforme d'achat et de réservation de motos neuves et d'occasion en ligne, avec livraison à domicile sous 72 heures.

## Stack Technique

- **Framework :** React 19 + TypeScript + Vite
- **UI & Style :** Tailwind CSS + Radix UI / Shadcn UI + Lucide Icons
- **Animation & Défilement :** GSAP + ScrollTrigger + Three.js + Lenis
- **Routage & SEO :** React Router DOM v7 + Structured Data (JSON-LD)

## Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Démarrage du serveur de développement
npm run dev

# Build de production
npm run build
```
